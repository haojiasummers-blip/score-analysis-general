# 成绩报表统计分析 · 方法步骤手册

> 适用对象：某市联考类「总分报表」（含县/学校/班级/姓名/学号/选科 + 各科原始分与赋分 + 各类排名）
> 配套脚本：`scripts/cross_sectional.py`、`scripts/longitudinal.py`
> 起草依据：某市高二物理组一次联考报表（约 8000 人 / 20 余校 / 8 科目）的完整实操

---

## 〇、总体流程

```
原始报表 → ① 读懂结构 → ② 扁平化 → ③ 样本描述
        → ④ 各科指标 → ⑤ 分布形态 → ⑥ 分数段
        → ⑦ 相对位置 → ⑧ 异常值 → ⑨ 分层比较
        → ⑩ 相关分析 → ⑪ 赋分效应 → ⑫ 贡献分解
        → ⑬ 撰写报告

（若有两期同一批学生的数据，另加 ⑭ 纵向增值分析 → 见第九章）
```

**每一步都要做一次校验**（见第三章）。校验不过，后面的数全部作废。

---

## 一、数据准备

### 1.1 先看清原始表长什么样

拿到报表第一件事：**不要急着算，先确认表头结构**。

常见三种：

| 类型 | 特征 | 例子 |
|---|---|---|
| **两行合并表头** | 第 1 行是分组名（总分/语文/数学…），第 2 行是子表头（原始分/赋分/班名/校名…） | 该市总分报表 |
| **单行表头** | 第 1 行就是完整列名 | 部分简化版 |
| **三行表头** | 标题行 + 分组行 + 子表头行 | 期末大榜类 |

**判断方法**：找到「姓名」所在的单元格，看它在第几行、它右边或下边有没有第二层名字。

### 1.2 扁平化（最关键的一步）

合并表头必须拆成单行表头，否则后续所有公式都会错位。

**规则**：
1. 分组行横向填充（合并单元格只有首格有值，要向右补齐）
2. 列名 = `分组名_子表头`，例如 `语文_分数(原始)`、`总分_赋分总分`
3. 分组名为空时直接用子表头

**示例结果**：

| 原结构 | 扁平化后 |
|---|---|
| 语文（合并 5 列） + 分数(原始) | `语文_分数(原始)` |
| 语文 + 班名 | `语文_班名` |
| 总分（合并 4 列） + 原始总分 | `总分_原始总分` |

**校验**：扁平化后列数 = 分组行非空列数；行数 = 原始数据行数，且「姓名」列无空值。

## 二、十二个分析层

### ① 样本概况

**目的**：先说清"这是谁的成绩"。

**内容**：
- 县区分布（人数 + 占比）
- 学校分布（按人数降序 + 占比）
- 选科构成（人数 + 占比）

**要点**：
- 学校规模差异可能极大（本例 979 人 vs 11 人，相差 89 倍）
- **必须标注小样本单位**（中职/艺术/特教类，n < 50），它们的均分不可与普通高中并列
- 选科构成决定总分构成，是后面所有"总分"分析的前提

---

### ② 各科描述统计

**指标**：n、均值、中位数、偏值、SD、P25、P75、IQR、CV、峰度

**Excel 公式**（以语文列 `N` 为例）：

| 指标 | 公式 |
|---|---|
| n | `=COUNT(扁平化!$N$2:$N$7928)` |
| 均值 | `=AVERAGE(...)` |
| 中位数 | `=MEDIAN(...)` |
| 偏值 | `=SKEW(...)` |
| SD | `=STDEV(...)` |
| P25 / P75 | `=QUARTILE(...,1)` / `=QUARTILE(...,3)` |
| IQR | `=P75-P25` |
| CV | `=SD/均值` |
| 峰度 | `=KURT(...)` |

**要点**：
- **SD 与 CV 的排序可能不同**。本例 SD 排序 数学>英语>语文>物理，CV 排序 数学>物理>英语>语文——物理从第 4 升到第 2，因为它满分只有 100、均分只有 30.93。
- **跨科比离散程度只能用 CV**，因为 SD 有量纲、会被满分绑架。
- 峰度 > 0 尖峰厚尾，< 0 平峰。

---

### ③ 分布形态（频数分布 + 单峰性）

**做法**：
1. 用组距 10 做频数分布，四科并排
2. 若怀疑多峰，再补做组距 20 与组距 5

**Excel 公式**（区间计数最可靠）：

```excel
=COUNTIFS(扁平化!$N$2:$N$7928,">="&$A10,扁平化!$N$2:$N$7928,"<"&$B10)
```

**最后一行必须用 `<=` 闭合**，否则满分的人会漏掉。

**单峰性判断**：三种组距下"峰的个数"一致 → 判定为单峰，无需再作形式化检验（如 Hartigan）。

**校验**：每列合计 = 该科有效人数。

**形态解读参考**：

| 形态 | 特征 | 本例 |
|---|---|---|
| 中间厚两头薄 | 峰值在中段，两端快速衰减 | 语文（89.7% 在 40~75% 得分率） |
| 逐档递减 | 每档人数约为上档的 2/3 | 英语 |
| 宽平台 | 相邻多档人数接近，无明显峰 | 数学（20~70 分五档都在 720~982） |
| 尖峰压底 | 一半人挤在低分窄区间 | 物理（49.2% 在 10~30 分） |

---

### ④ 分数段结构

**做法**：按**得分率**分档（40% / 60% / 75% / 90%），不是按原始分。

**阈值换算**：`阈值 = 满分 × 得分率`

| 档位 | 满分 150 | 满分 100 |
|---|---|---|
| 后 40% | < 60 | < 40 |
| 40~60% | 60 ~ 90 | 40 ~ 60 |
| 60~75% | 90 ~ 112.5 | 60 ~ 75 |
| 75~90% | 112.5 ~ 135 | 75 ~ 90 |
| ≥ 90% | ≥ 135 | ≥ 90 |

> **换算诀窍**：100 分制阈值 = 150 分制阈值 × 2/3。

**要点**：
- **这是唯一能直接指导教学决策的一层**，因为输出是"多少人"
- 及格率（≥60% 得分率）往往比均值有解释力得多（本例语文 47.9% vs 物理 7.1%，差近 7 倍）
- 表格建议做**斜线表头**：`得分率` 在右上、`学科` 在左下

**校验**：每行五档之和 = 该科有效人数 = 校核列。

---

### ⑤ 相对位置（z 分与百分位）

**做法**：
1. 用各科均值与 SD 算 z 分
2. 取几个 z 点（−2、−1.5、−1、−0.5、0、0.5、1、1.5），比较"正态假设的百分位"与"实际百分位"

**公式**：

```excel
z 分      =IF(N2="","",(N2-县区!$B$28)/县区!$E$28)
正态 PR   =NORM.S.DIST(z,TRUE)*100
实际 PR   =PERCENTRANK(扁平化!$N$2:$N$7928, 分数)*100
```

**要点**：
- **z 分不能跨考试比较**（两次考试均值/SD 不同）
- **百分等级不等距**，不能求平均
- 偏斜严重时（|偏值|>1）优先用实际百分位，不要用正态表
- **本例发现**：语文均值 85.43 的正态百分位是 50%，实际只有 **41.4%**——左偏分布中均值已被长尾拽低，不再是"中间那个人"

---

### ⑥ 异常值

**两种法则**：

| 法则 | 判据 |
|---|---|
| IQR 法则 | `< Q1 − 1.5×IQR` 或 `> Q3 + 1.5×IQR` |
| z 法则 | `\|z\| > 3` |

**Excel 公式**：

```excel
=IF(N2="","",IF(OR(N2<县区!$F$28-1.5*县区!$H$28, N2>县区!$G$28+1.5*县区!$H$28),"异常",""))
=IF(BG2="","",IF(ABS(BG2)>3,"异常",""))
```

**要点**：
- **异常值方向 = 偏斜方向**：左偏的科目异常在下端，右偏的在上端
- **"1.5×IQR ≈ 2.7 SD" 只在正态下成立**。本例语文的 1.5·IQR 只相当于 2.2 个 SD，所以 IQR 法则必然比 z 法则宽松
- ⚠️ **"z 法则 ⊂ IQR 法则"并非普遍成立**。本例语数英物四科成立，但**生物例外**（仅 z 标出 2 人）。必须逐科核对「仅 z」列
- **不要剔除异常值**。它们是真实的极端得分，剔除会系统性美化均值

**缺考与真 0 分的区分**：
- 单元格为**空** → 缺考，不计入
- 单元格为 **0** → 真实得分，计入
- 若某科 0 分且总分也缺失，需向学校核实是否缺考被记为 0

---

### ⑦ 分层比较

**做法**：数据透视表，行 = 学校，值为各科**平均值** + 姓名**计数**

**WPS 步骤**：
1. 点数据表任意单元格 → 插入 → 数据透视表
2. **位置选「新工作表」**（否则报"不能与表或XML映射重叠"）
3. 行：`学校`；值：各科 `_分数(原始)` + `姓名`
4. **每个值字段右键 → 值字段设置 → 改成「平均值」**（默认是求和！）

**校验**：总计行应等于全市均值。

**要点**：
- **看均分必须同时看人数**，否则小样本学校会被误读
- **校际差异往往是整体性的**：本例四科排名高度同序，说明差距来自生源入口而非单科教学
- **不能据校均分评价教学水平**（需入口成绩做基准）

---

### ⑧ 相关分析

**做法**：同时算 Pearson 与 Spearman。

**公式**：

```excel
=CORREL(扁平化!$N$2:$N$7928, 扁平化!$S$2:$S$7928)          ← Pearson
=IF(N2="","",RANK.AVG(N2,$N$2:$N$7928,0))                  ← 秩（并列取平均）
=CORREL(秩列1, 秩列2)                                       ← Spearman
```

**要点**：
- 原始分严格属**定序**量表（0 分不是绝对零点），故 **Spearman 更稳妥**
- **差值的符号随偏度方向变化**：与左偏科目配对时 Spearman 更高，与右偏科目配对时 Pearson 更高
- **r 是"关系强度"，r² 是"解释比例"，不要用 r² 判强弱**。全部 0.57~0.80 是"大"效应量
- **教育测验学科间相关通常 0.3~0.6**，本例偏高；相关接近 1.0 反而说明两科在测同一件事

**三个必须警惕的陷阱**：

| 陷阱 | 表现 | 应对 |
|---|---|---|
| **部分-整体相关** | r(科目, 总分) 虚高 | 计算基线 `SD_i/√ΣSD²`，看"高出基线多少" |
| **全距限制** | 分组后相关骤降 | 报告相关系数必须注明计算范围 |
| **选考科目重叠样本** | 两科相关只对同选者成立 | 同时选考人数 < 10 时不计算 |

### ⑨ 赋分效应

**做法**：对有赋分的科目，并列比较原始分与赋分的各项指标。

**要点**：
- **赋分 = 相对位置，不是"得分能力"**。实测原始分与赋分的 Spearman ≈ 1.000，说明赋分未增加信息
- **均值被拉平**：本例四科原始均值 35.54~55.58（差 20），赋分后 68.56~72.18（差 3.6）
- **离散被压缩**：CV 由 0.308~0.533 压到 0.180~0.217，**不可用赋分 CV 比较各科分化**
- **偏度翻转、峰度上升**：因赋分有 100 上限，尾部向低分一侧拖长
- **参试群体不同会产生选择效应**：本例化学 95.9% 的人都考，政治只有 13.1%

---

### ⑩ 贡献分解

**先分清四种"贡献"**：

| 含义 | 能否算 | 条件 |
|---|---|---|
| 分差分解（总分差里各科各占多少） | 能（精确） | 现数据 |
| 方差贡献率（总分差异与哪科关联强） | 能 | 现数据 |
| 纵向增值（某科进步对总分进步的贡献） | 不能 | 第二次考试 |
| 因果效应（加强某科能提升多少） | 不能 | 实验/准实验 |

#### 分差分解

**前提**：确认恒等式 `总分 = 语+数+英+物+选考1赋分+选考2赋分` 逐人成立。
本例验证：可验证 7541 人，**误差 < 0.5 分的比例 100.00%，最大误差 0.00**。

**做法**：各科均值 − 全市均值，四者之和即小计差。

**占比规则**：`占比 = 该科分差 / 小计差`
⚠️ **小计差绝对值 < 10 分时，占比失真，只报绝对分差。**

#### 方差贡献率

$$\text{贡献率}_i = r_i \times \frac{SD_i}{SD_{总分}}$$

四项**合计恒为 100%**。

本例：数学 33.5%、英语 31.7%、语文 17.4%、物理 17.3%。

> **注意**：这是方差归因，**不是因果效应**。不能说"提高数学能提升 33.5% 的总分"。

## 三、校验清单（每步必须对）

| 步骤 | 校验项 | 应等于 |
|---|---|---|
| 扁平化 | 行数 | 原始数据行数 |
| 各科指标 | n | `COUNT(该列)` |
| 频数分布 | 各列合计 | 该科有效人数 |
| 分数段 | 五档之和 | 有效人数 = 校核列 |
| 分层 | 透视表总计 | 全市均值 |
| 相关 | n | 两科同时非空的行数 |
| 赋分对比 | 原始 n | 赋分 n |
| 贡献分解 | 四项之和 | **100.0%** |
| 分差分解 | 四科分差之和 | 小计差 |
| **纵向·配对** | 配对样本 | 两期交集（> 85% 判同批） |
| **纵向·恒等式** | ΣΔ各科 | Δ总分（误差 < 0.5 应 > 99%） |
| **纵向·标准分** | ΣΔSS | ΔSS总（构造上应精确） |

## 四、踩坑记录

| # | 坑 | 症状 | 修法 |
|---|---|---|---|
| 1 | **最后一组没闭合** | 合计少几人，恰好是满分那批 | 末组用 `<=` |
| 2 | **组限每行跳 20 而非 10** | 合计正好是真值一半 | 每列从自己上一格递增，别跨列引用 |
| 3 | **引用空格当 0** | 异常值标出几乎全体 | 核对引用单元格是否为空 |
| 4 | **空格参与减法** | `#VALUE!` 成百上千 | `=IF(N2="","",公式)` |
| 5 | **绝对引用不随行变** | 数学那行显示语文的数 | 每行手动改列字母，不能整列下拖 |
| 6 | **引用错科目列** | 物理的分布其实是化学的 | 用"合计=该科人数"反查 |
| 7 | **行列区间偏移** | 合计少 9 个 | 检查 `$2:$7928` 是否写成 `$11:$7937` |
| 8 | **透视表叠在表上** | 报"不能与表或XML映射重叠" | 位置选「新工作表」 |
| 9 | **透视表默认求和** | 均值列显示成几万 | 值字段设置改为「平均值」 |
| 10 | **名称框选区后 Ctrl+D 失灵** | 快捷键无反应 | 按一下方向键，或改用复制粘贴 |
| 11 | **`PERCENTRANK.INC` 不认** | `#NAME?` | 改用 `PERCENTRANK` |
| 12 | **百分位超出分数范围** | `#N/A` / `#NUM!` | 把 z 值调到分数不超上限 |
| 13 | **`IFERROR` 包住一切** | 真错误被静默吞掉 | 只在确定条件下用 `IF` |
| 14 | **衰减校正超出 1** | 修正后 r² > 1，数学上不可能 | 该值说明假设信度不足，或该相关不适合校正（部分-整体） |

## 五、措辞边界（能说 / 不能说）

| 能说 | 不能说 |
|---|---|
| 两班的数学属于同一水平档 | 两班教学水平相当 |
| 语文均分排在 41.4 百分位 | 语文教学拖了后腿 |
| 中间 50% 学生跨 22 分 | 中间的学生不容易被拉开 |
| 数学与英语是总分差异的主要来源 | 提高数学能提升 33.5% 的总分 |
| 我校与全市差 113.7 分，英语占 32% | 我校英语教得不好 |
| 四科相关 0.57~0.80，属大效应量 | 四科关联不大，因为 r² 不到五成 |

**根本原因**：校际效应量（标准化均值差）常达 2~4.5，远高于一般教育研究的 0.2~0.8，反映的是极端生源分层，不是教学质量差异。

## 六、报告结构模板

```
一、数据与口径        （样本量、原始分/赋分规则、缺失值处理）
二、样本概况          （县区、学校、选科）
三、总体成绩水平      （各科指标表 + 两三点判断）
四、分布形态与分数段  （单峰性、分段表、形态解读）
五、校际差异          （极差表、整体性判断）
六、科目间关联        （两两相关、部分-整体、全距限制）
七、总分差距的科目构成 （四种贡献的边界、恒等式验证、方差贡献、分差分解）
八、选考科目的赋分效应 （双口径对比、三个效应、使用限定）
九、异常值处理        （双法则对比、不剔除的理由）
十、主要结论          （每人一句，可独立摘用）
十一、限制与说明       （横断面、未校正、无信度、"不能说什么"）
```

**写作三原则**：
1. **每个数可回溯**（注明来自哪张表哪一列）
2. **结论与解释分离**（"是什么"用数据说，"为什么"单独写并标明确定程度）
3. **把"不能说什么"写进限制章**——这是保护报告不被误用的关键

## 七、脚本用法

### 7.1 横断面分析

```powershell
python scripts/cross_sectional.py <成绩报表.xlsx> [输出.xlsx]
```

**自动完成**：扁平化、样本概况、各科指标、分数段、频数分布、相关矩阵、异常值、赋分对比、贡献分解、分差分解、百分位对照。

**自动识别的表结构**：两行合并表头 / 单行表头 / 三行表头。

### 7.2 纵向增值分析（两期数据）

```powershell
python scripts/longitudinal.py <A期.xlsx> <B期.xlsx> [输出.xlsx]
```

**自动完成**：配对（含同校同名消歧）、两期全样本对比、原始分变动、标准分变动、百分位变动、标准分分解、校级对比、个人明细。

详见第九章。

**需要人工确认的**：
- 满分配置（脚本内置 语数英=150、其余=100，如不符请改 `FULL_MARKS`）
- 哪些科目计入"小计"（`CORE_SUBJECTS`）
- 各科异常值是否合理（逐科看「仅 z」列）
- 学校类型（中职/艺术类需单独标注）

**输出**：多工作表 xlsx（含「说明」页记录本次分析的口径与限制）。

## 八、下次拿到新报表时的最短路径

1. 跑脚本 → 看控制台的校验锚点是否全绿
2. 人工核对：`分数段合计 = 校核`、`贡献率 = 100%`
3. 打开「说明」页确认满分与科目识别正确
4. 按第六章模板写报告，重点补：样本概况的文字描述、形态解读、校际差异的实际含义
5. 若要做纵向对比（进步/增值），需**两期报表**且能按学号或姓名+学校+班级稳定匹配

> ⚠️ **匹配陷阱**：本类报表的"学号"列很可能是**每场重排的考号**（本例 10 份文件出现 9 种不同学号，跨 6 套前缀）。跨考试追踪学生应以「姓名 + 学校 + 班级」为准，并对同名同校情况向学校核实。

## 九、纵向增值分析（需要两期数据）

> 本章回答"学科对总分的贡献"这一问题的**纵向版本**——前八章只能做横断面，本章需要同一批学生的两次考试。

### 9.1 先确认是同一批人

| 检验项 | 做法 | 本例结果 |
|---|---|---|
| 姓名交集 | A、B 两期唯一姓名的交集 / 较多一方 | **93.3%** |
| 规模对比 | 两期行数 | 6683 → 7021 |
| 选科构成 | 各组合人数是否稳定 | 物化生 4378→4654 ✓ |

**姓名交集 > 85% 且选科构成稳定 → 判定同一批人。**

### 9.2 配对键：不要用完整学号

**实测（6408 对安全配对样本）学号前缀一致率：**

| 前缀长度 | 一致率 |
|---|---|
| 前 4 位 | 99.7% |
| 前 8 位 | **94.7%** |
| 前 9 位 | 91.5% |
| 前 12 位（全号） | **32.2%** ❌ |

**后 2~3 位每场重排，完整学号只有三成能对上。**

**推荐做法**：

```
主键：姓名 + 学校          → 保住 91.6% 样本
消歧：同校同名的少数人，用「学号前 8 位」区分
```

各键可配对率对比：

| 匹配键 | 可配对 | 占 B 期 |
|---|---|---|
| 姓名 | 6346 | 90.4% |
| **姓名+学校** | **6432** | **91.6%** |
| 姓名+学校+班级 | 5954 | 84.8% |
| 姓名+学校+学号（全） | 2081 | **29.6%** ❌ |

### 9.3 两种口径必须同时报

| 口径 | Δ 的构成 | 是否精确可加 | 是否含试卷难度 |
|---|---|---|---|
| **原始分 Δ** | 原始分 B − A | ✅ `ΣΔ各科 = Δ总分` | ❌ **含** |
| **标准分 Δ** | 标准分 B − A | ✅ `ΣΔSS = ΔSS总` | ✅ **不含** |

**只用其中一个都会误导。**

### 9.4 标准分（正态化标准分）构造

```
1. PR = (秩 − 0.5) / n          每科每期独立计算，n = 该科当期有效人数
2. z  = Φ⁻¹(PR)                 正态反函数，PR 截断到 [1e-6, 1−1e-6]
3. SS = 满分×0.5 + z×(满分/6)    均值=满分50%，SD=满分1/6
   并截断到 [0, 满分]
```

**关键性质**：
- 各科回到原满分尺度（语数英 150、物理 100、选考两门各 100）
- 标准总分满分 = 750，均值 ≈ 375
- **各科同尺度 → 分解可加**
- **每期独立 → 难度被消除**

### 9.5 ⭐ 一个极简的难度判别指标：上升率

**规则**：

> 若某科**原始分上升率远离 50%**，而**标准分上升率接近 50%**，则变化来自**试卷难度**，不是学生。

**本例实证：**

| 科目 | 原始分 Δ | 标准分 Δ | 原始上升率 | 标准上升率 |
|---|---|---|---|---|
| 语文 | **+8.04** | **−0.51** | **79.9%** | **47.8%** |
| 数学 | +1.15 | −0.55 | 52.3% | 48.4% |
| 英语 | −1.08 | −0.42 | 44.6% | 48.0% |
| **物理** | **−10.66** | **−0.33** | **15.0%** | **48.7%** |

**语文涨 8 分、物理跌 11 分，在标准分口径下都塌缩到 −0.5 附近 —— 全是难度。**

### 9.6 占比门槛：分母太小就不报

**规则**：`|平均总分变动| < 5 分时，不报告"各科占比"`。

原因：本例原始分口径平均总分只变 −3.09 分，而各科在 ±11 之间反向抵消。此时 −10.66 ÷ −3.09 = 365% 这类数字毫无意义。

**标准分口径同样适用**：平均 −2.67 分，各项 −0.3~−0.9，占比一律置空。

### 9.7 校级对比：原始分与标准分排序可能完全不同

**本例三处错位：**

| 学校 | 原始分 Δ | 标准分 Δ | 含义 |
|---|---|---|---|
| 学校 A | **+5.27（原始第1）** | +0.30（第4） | "进步"多半来自难度 |
| 学校 B | −2.74（看似退步） | **+0.76（第1）** | 相对位置实际上升 |
| 学校 C | +0.13（几乎不变） | **−5.13（倒数第3）** | 原始分掩盖了下滑 |

> **结论：不能用原始分的校际差评价学校。** 原始分的校际差异主要反映各校对难度变化的"暴露度"不同（哪科占比大、哪科难度变化大）。

### 9.8 必须写进报告的三条限制

1. **标准分只反映相对位置**，不反映绝对掌握程度。若全体一起变难，标准分不变——这是设计使然。
2. **两期参试人数不同**会让各科标准分 Δ 系统性偏负（本例新增 338 人，各科 Δ 均为 −0.3~−0.9）。
3. **标准分 Δ 不能替代"学生学得更好/更差"的判断**，只能回答"相对位次怎么变"。

### 9.9 输出结构

| 工作表 | 内容 |
|---|---|
| 说明 | 配对方式、样本量、口径、限制 |
| 两期全样本对比 | 各科均值，**看难度变化的第一眼** |
| 原始分变动 | 各科 Δ 的分布与上升率 |
| 标准分变动 | 同上，但已去难度 |
| 百分位变动 | 最直观的版本（单位：百分位点） |
| 标准分分解 | 各科贡献，合计 100% |
| 校级变动 | 各校两种口径并列 |
| 个人明细 | 每人每科的 ΔSS / ΔPR / ΔRAW |

### 9.10 踩坑（纵向专属）

| # | 坑 | 症状 | 修法 |
|---|---|---|---|
| 15 | **用完整学号配对** | 只剩 30% 样本 | 用前 8 位，或改用姓名+学校 |
| 16 | **只报一个口径** | 读者以为是同一个数 | 原始 Δ 与标准 Δ 并列 |
| 17 | **把原始 Δ 读成进步** | 语文+8 被当成"语文教学成果" | 先看上升率是否接近 50% |
| 18 | **占比分母过小** | 出现 300%+ 的荒谬占比 | 总量 \|Δ\| < 5 时不报占比 |
| 19 | **忽略参试人数变化** | 标准分 Δ 全偏负却找不到原因 | 报告新增/流失人数 |
| 20 | **同校同名未消歧** | 配错人，Δ 出现极端值 | 用学号前 8 位消歧；配不上的剔除 |
