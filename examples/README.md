# 示例：600 人合成数据

这里的成绩**全部是随机生成的**，不对应任何真实学校、任何真实考试。
姓名是「同学001…同学600」，学校是「示例一中…示例五中」，班级 1–6 班。

## 跑一遍

```bash
# 1) 生成两份合成报表（A 期、B 期，同一批学生）
python examples/make_example_data.py

# 2) 单期横断面：13 张表
python scripts/cross_sectional.py examples/样例_A期.xlsx

# 3) 两期纵向增值：8 张表
python scripts/longitudinal.py examples/样例_A期.xlsx examples/样例_B期.xlsx

# 想一次跑完并把输出存成文本
python examples/run_example.py
```

生成的文件（`样例_A期.xlsx`、`_输出_*.xlsx`）已被 `.gitignore` 排除，不会进仓库。

## 数据长什么样

刻意做成真实报表最常见的样子——**两行合并表头**：

| 第 1 行 | 区 | 学校 | 班级 | 姓名 | 学号 | 选科 | 总分（合并 6 列） | 语文（合并 5 列） | … |
|---|---|---|---|---|---|---|---|---|---|
| 第 2 行 | | | | | | | 原始总分 / 赋分总分 / 班名 / 校名 / 市名 / 联名 | 分数(原始) / 班名 / 校名 / 市名 / 联名 | … |

600 人 × 44 列；A 期、B 期是同一批学生（学号、姓名一致）。
B 期刻意把**语文整体抬高 8 分、数学抬高 2 分**，用来演示「难度变化」怎么识别。

## 预期结果（对照 `expected_output.txt`）

横断面：

```
样本量: 600
识别到科目: 语文(原始), 数学(原始), 英语(原始), 物理(原始), 化学(原始+赋分), 生物(原始+赋分)
分数段合计与有效人数不一致的科目: 无
贡献率合计 = 100.00%
各项贡献率: 语文=17.9%  数学=32.0%  英语=26.9%  物理=23.2%
```

纵向增值：

```
配对样本 N = 600        完全案例 N = 600

语文（原始分）  +8.01 分   上升率 72.7%
语文（标准分）  +0.00 分   上升率 52.2%
```

**这就是技能要抓的形态**：原始分涨了 8 分、上升率 72.7%，但标准分几乎不动、上升率 52.2%
——那 8 分是卷子变简单，不是学生变强。

还能看到「占比门槛」生效：

```
标准分分解：合计 -0.0049 分 → 占比全部置空
注: 平均标准总分变动仅 -0.00 分，各科接近 0，占比不稳定，故不予报告。
```

## 换成你自己的数据

照 `样例_A期.xlsx` 的结构准备表即可：第 1 行分组名、第 2 行子表头、第 3 行起数据，
列名包含 `分数(原始)`、`总分`、`原始总分`、`班名/校名/市名` 这些关键词。
单行表头、三行表头也能自动识别。
